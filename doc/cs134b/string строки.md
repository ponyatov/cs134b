# 2.2.5 string: строки

Строки в [[OCaml/OCaml|OCaml]] представляют собой последовательности символов переменной длины, заключённые в двойные кавычки. Они являются неизменяемыми (immutable) объектами, но для эффективности допускают частичное мутабельное обновление через библиотечные функции. Для работы со строками предоставляется модуль `String`, содержащий функции для конкатенации, поиска, извлечения подстрок и других операций.
