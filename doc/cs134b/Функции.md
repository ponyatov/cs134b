# 3.1 Функции

Функции определяются также с помощью `let`, но с указанием параметров:

```ocaml
let add x y = x + y;;
```

Эта функция принимает два аргумента `x` и `y` и возвращает их сумму. Типы аргументов и возвращаемого значения выводятся автоматически. В данном случае `add` имеет тип `int -> int -> int`.
