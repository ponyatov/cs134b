# 1.1 Инструментарий OCaml

1. Установка [[opam]] (Ocaml PAcket Manager)
	```sh
	$ bash -c "sh <(curl -fsSL https://opam.ocaml.org/install.sh)"
	$ which opam
	/usr/local/bin/opam
	```
2. Инициализация opam
	- После установки необходимо инициализировать opam для настройки среды. Это создаст домашний каталог `~/.opam`:
		```sh
		$ opam init --bare --disable-sandboxing -a
		```
3. После инициализации доабавьте команду в dot-файлы, чтобы добавить пути к исполняемым файлам OCaml в вашу текущую оболочку:
	```sh
	eval $(opam env)
	```
4. opam switch это тулчейн (рабочее окружение), включающий определённую версию компилятора и связанным с ним пакетов. `opam` без флага `-a` при инициализации создаёт только один switch по умолчанию (`default`), но для работы над конкретным проектом или с определённой версией OCaml рекомендуется создать новый вручную:
	- глобальный: устанавливается индивидуально для пользователя, но для всех его проектов (switch по умолчанию)
	```sh
	$ opam switch create cs134b ocaml-base-compiler.5.4.0
	$ opam switch list
	$ ocaml --version
	```
	- локальный для проекта: создаётся внутри каталога проекта, и обеспечивает полную изоляцию зависимостей для этого проекта
		- `opam` будет использовать файлы `dune-project` и `.opam` для определения версии компилятора, которую нужно установить
			```
			opam switch create .
			```
5. Установка инструментов разработки
	```
	opam install -y utop dune ocamlformat ocaml-lsp-server ppx_string menhir
	```
	- [[utop]]: современный интерактивный интерпретатор (REPL = ocamltop shell)
	- [[dune]]: система сборки проектов
	- [[ocamlformat]]: инструмент для автоматического форматирования кода
	- [[ocaml-lsp-server]]: cервер языковой поддержки в IDE (VS Code, Vim, Emacs)
	- [[ppx_string]]: библиотека интерполяции строк
	- [[menhir]]: генератор синтаксических парсеров (чтение текстовых форматов данных)
	- [[camlp5]]: препроцессор и система парсинга для расширения синтаксиса
6. Настройка dot-файлов (можно локально для отдельного проекта)
	- ~/.ocamlinit
		![[cs134b/ocamlinit]]
	- ~/.ocamlformat
		- `echo "version = `ocamlformat --version`" > ~/.ocamlformat`
			![[cs134b/ocamlformat]]
7. Обновление (при необходимости перехода на свежие версии)
	```
	opam update && opam upgrade
	```
8. Настройка [[vscode/VSCode|VSCode]]:
	- установите расширение [[ocamllabs.ocaml-platform]]
