# 5. Кортежи, списки и полиморфизм

OCaml предлагает богатый набор типов для определения структур данных, включая кортежи, списки, размеченные объединения (также называемые вариантами или вариантивными записями), записи и массивы. В этой главе мы рассмотрим простейшие из них — кортежи и списки.

Кортежи и списки представляют собой фундаментальные строительные блоки для организации данных в OCaml. Они позволяют группировать значения и работать с коллекциями, а также служат основой для реализации более сложных структур.

**Кортежи** — это упорядоченные коллекции фиксированной длины, элементы которых могут быть разных типов. Кортеж размещается в памяти как единый блок, что обеспечивает эффективный доступ к его компонентам. Тип кортежа определяется как декартово произведение типов его элементов. Например, кортеж `(42, "hello", true)` имеет тип `int * string * bool`.

**Списки** — это однородные последовательности переменной длины, где все элементы имеют одинаковый тип. Списки в OCaml являются односвязными и неизменяемыми. Они строятся с помощью конструкторов: пустого списка `[]` и операции добавления элемента в голову `::`. Тип списка записывается как `тип_элемента list`, например, `int list` для списка целых чисел.

Полиморфизм в OCaml позволяет писать обобщённые функции, работающие с кортежами и списками различных типов. Например, функция `fst`, возвращающая первый элемент пары (кортежа из двух элементов), имеет полиморфный тип `'a * 'b -> 'a`. Аналогично, многие функции для работы со списками (такие как `List.map`, `List.filter`) являются полиморфными и могут применяться к спискам произвольного типа.
