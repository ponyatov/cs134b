# 5.1 Полиморфизм

Полиморфизм в OCaml является одним из ключевых механизмов, позволяющих писать гибкий и обобщённый код, оставаясь в рамках строгой статической типизации. В отличие от многих императивных языков, где полиморфизм часто связан с наследованием и динамическим связыванием, в OCaml он в первую очередь выражается через **параметрический полиморфизм** — возможность определять функции и типы, работающие с данными произвольного типа без потери безопасности типов.

**Параметрический полиморфизм** проявляется, когда функция или тип содержит **переменные типа** (type variables), обозначаемые апострофом и буквой, например `'a`, `'b`. Компилятор OCaml автоматически выводит наиболее общий тип для выражений, что позволяет использовать одну и ту же функцию с разными типами данных. Классический пример — функция `List.length`, которая имеет тип `'a list -> int`. Она работает со списками любого типа, поскольку не зависит от содержимого списка, а только от его структуры.

```ocaml
(* Пример полиморфной функции *)
let identity x = x  (* тип: 'a -> 'a *)
let first (x, _) = x  (* тип: 'a * 'b -> 'a *)

let lst1 = [1; 2; 3]
let lst2 = ["a"; "b"; "c"]

let len1 = List.length lst1  (* int *)
let len2 = List.length lst2  (* int *)
```

**Полиморфизм в структурах данных** также естественным образом поддерживается. Например, тип кортежа `('a * 'b)` является полиморфным по обоим компонентам. Тип списка `'a list` полиморфен по типу элементов. Это позволяет создавать обобщённые контейнеры и алгоритмы, такие как функции отображения (`map`), фильтрации (`filter`) или свёртки (`fold`).

```ocaml
(* Полиморфный тип списка *)
let rec map f = function
  | [] -> []
  | h :: t -> f h :: map f t
(* тип: ('a -> 'b) -> 'a list -> 'b list *)
```

**Ограничения и специализация.** Несмотря на общность, полиморфизм в OCaml не означает “работа с чем угодно”. Система типов гарантирует, что полиморфная функция не может выполнять операции, специфичные для конкретного типа (например, арифметику над `'a`). Если требуется такая специализация, используются механизмы **ограниченного полиморфизма** (например, функции с ограничениями через модули или объекты), которые будут рассмотрены в дальнейших главах.
