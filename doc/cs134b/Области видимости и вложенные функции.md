# 3.1.1 Области видимости и вложенные функции

В OCaml область видимости переменных и функций определяется **лексическим контекстом**, то есть местом в коде, где они объявлены. Это позволяет создавать вложенные функции и управлять доступом к данным, обеспечивая модульность и предотвращая нежелательные взаимодействия между частями программы.

## Локальные определения с `let ... in`

Конструкция `let <определение> in <выражение>` создаёт локальную область видимости: переменная или функция, определённая в `<определении>`, доступна только внутри `<выражения>`.

```ocaml
let outer = 10 in
	let inner = outer * 2 in
		inner + 5;;  (* Результат: 25 *)
```

- `outer` видна во всём блоке после первого `in`.
- `inner` видна только в выражении `inner + 5`.

## Вложенные функции

Функции можно определять внутри других функций. Такие вложенные функции имеют доступ к параметрам и переменным внешней функции — это называется **замыканием** ([[lang/closure|closure]]).

```ocaml
let multiply_by n =
  let multiplier x = n * x in
	  multiplier;; (* return function *)

let double = multiply_by 2;;
let triple = multiply_by 3;;

double 5;;  (* 10 *)
triple 5;;  (* 15 *)
```

- запустите VSCode: `code ~/cs134b`
- создайте пустой файл `code lib/workpad.ml`
	- скопируйте в него определение функции `multiply_by`
- выделите определение функции и нажмите [Ctrl]+[Enter]
	- при правильно настроенной рабочей во встроенном терминале запутится [[top]]
	- и в нём выполнится выделенный код
	- при необходимости в конец выражения добавляется `;;` обозначающей конец блока кода, который нужно выполнить в REPL

```ocaml
utop # let multiply_by n =
	let multiplier x = n * x in
		multiplier;; (* return function *)
```
```ocaml
val multiply_by : int -> int -> int = <fun>
```

- выражение вычисляется в функцию, получающую на вход `a` и возвращающую `b`
```ocaml
utop # multiply_by 2;;
- : a:int -> b:int = <fun>
```
- при использовании let ей присваивается имя:
```ocaml
utop # let double = multiply_by 2;;
val double : int -> int = <fun>
```
- функция вызывается без использования скобок для аргументов:
```ocaml
utop # triple 5;;  (* 15 *);;
- : int = 15
```

Функция `multiplier`
- «запоминает» значение `n` из внешнего контекста даже после того, как `multiply_by` завершила выполнение
- и вернула новую анонимную функцию с подставленным `n`

## Сокрытие имён (shadowing)

Если внутри области видимости определить переменную с именем, уже существующим во внешней области, новая переменная **затенит** (shadow) старую. Это не изменяет исходную переменную, а создаёт новую связь имени со значением.

```ocaml
let x = 1 in
let x = x + 1 in  (* Здесь x == 2 *)
x;;  (* 2 *)
```

После выхода из внутреннего блока внешнее значение `x` снова становится доступным.
