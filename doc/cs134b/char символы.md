# 2.2.4 char: символы

Тип `char` представляет отдельный символ, заключённый в одинарные кавычки, например `'a'`, `'\n'`, `'\x20'`. Символы в [[OCaml/OCaml|OCaml]] являются 8-битными значениями (в кодировке Latin-1) и поддерживают сравнение и преобразование в целые числа с помощью функций `Char.code` и `Char.chr`.
