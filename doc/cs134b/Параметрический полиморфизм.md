# Параметрический полиморфизм

Система типов поддерживает **параметрический полиморфизм**, позволяя писать обобщённые функции, которые могут работать с данными любого типа. Полиморфные типы обозначаются символами с апострофом: `'a`, `'b`, `'c` и т.д.

```ocaml
(* Полиморфная функция: работает для списка элементов любого типа 'a *)
let rec length = function
  | [] -> 0
  | _ :: tl -> 1 + length tl
(* val length : 'a list -> int *)

(* Стандартные полиморфные функции *)
let fst (x, _) = x    (* val fst : 'a * 'b -> 'a *)
let snd (_, y) = y    (* val snd : 'a * 'b -> 'b *)
let id x = x          (* val id : 'a -> 'a *)
```
