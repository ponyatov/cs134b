# 3.2 Имена переменных

В OCaml, как и в большинстве языков программирования, имена переменных используются для обозначения значений в программе. Однако в контексте функционального программирования термин «переменная» имеет несколько иное значение, чем в императивных языках: в OCaml переменные являются неизменяемыми ([[immutable]]) **связываниями значений с именами**. После того как значение связано с именем, его нельзя изменить в той же области видимости. Это способствует написанию безопасного и предсказуемого кода, так как исключает неожиданные изменения состояния.

## Правила именования

Имена переменных в OCaml должны соответствовать следующим правилам:

- Начинаться со строчной буквы или символа подчёркивания `_`
- Состоять из букв (латинских), цифр, символов подчёркивания и апострофов `'`
- Не могут совпадать с ключевыми словами языка (`let`, `in`, `if`, `then`, `else`, `match`, `with` и т.д.)

Примеры допустимых имён:
```ocaml
let x = 5
let result_value = 42
let counter' = 0
let _private = true
```

## Особые имена

- Имена, начинающиеся с подчёркивания `_`, обычно указывают на намеренно неиспользуемые значения (например, при сопоставлении с образцом):
	```ocaml
	let _, y = (1, 2)  (* игнорируем первый элемент кортежа *)
	```
- Имена с апострофом `'` часто используются для обозначения «обновлённых» версий значений или временных переменных:
	```ocaml
	let x' = x + 1
	let rec fact n = 
	  let fact' acc k = ... in
	  fact' 1 n
	```

## Аннотации типов

OCaml автоматически выводит тип переменной на основе значения, с которым она связана. Аннотации типов не обязательны, но могут быть указаны для ясности:
```ocaml
let (x : int) = 42
let (name : string) = "OCaml"
```

## Неизменяемость

Неизменяемость переменных в OCaml имеет важные последствия:

- **Безопасность параллелизма**: отсутствие изменяемого состояния упрощает написание многопоточного кода
    
- **Упрощение рассуждений о коде**: значение переменной постоянно в своей области видимости
    
- **Оптимизации компилятора**: неизменяемость позволяет проводить агрессивные оптимизации

Однако для случаев, когда изменение состояния необходимо, OCaml предоставляет **ссылочные ячейки** (`ref`), **изменяемые поля записей** и **массивы**. Но даже эти механизмы используются в контролируемой манере, с явным указанием на мутабельность.
