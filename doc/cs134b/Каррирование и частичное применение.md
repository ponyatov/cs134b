# Каррирование и частичное применение

В OCaml все функции по умолчанию являются **каррированными** (curried). Это означает, что функция, принимающая несколько аргументов, фактически представляет собой цепочку функций одной переменной.

```ocaml
let add x y = x + y
```

Функция `add` имеет тип `int -> int -> int`, что интерпретируется как `int -> (int -> int)`. Это позволяет выполнять **частичное применение** (partial application):

```ocaml
let add_five = add 5  (* функция, которая прибавляет 5 к своему аргументу *)
let result = add_five 3  (* 8 *)
```

Частичное применение — мощный инструмент для создания специализированных функций на лету, уменьшения дублирования кода и повышения его выразительности.
