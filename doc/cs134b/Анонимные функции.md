# Анонимные функции
## лямбда-выражения

Для создания функций «на месте» без явного объявления имени используется синтаксис `fun`:
```ocaml
fun <args> -> <body>
```
```ocaml
let list = List.map (fun x -> x * x + 1) [1; 2; 3]
```

Анонимные функции особенно удобны в сочетании с функциями высшего порядка, когда требуется короткая одноразовая операция.
