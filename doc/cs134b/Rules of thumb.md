# Rules of thumb
## Правила использования

1. **Именованные аргументы** улучшают ясность вызовов функций с несколькими параметрами одного типа
    
2. **Опциональные параметры** должны идти после обязательных параметров
    
3. Функции с опциональными параметрами требуют завершающего `()` (unit-аргумента) для устранения неоднозначности
