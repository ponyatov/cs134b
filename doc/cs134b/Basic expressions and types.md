# Basic expressions and types
## Базовые выражения и типы

Каждое простое выражение в OCaml обладает статическим типом. Тип определяет природу значения (целое число, строка, логическое значение) и набор операций, которые к нему применимы.

2.2.1 [[cs134b/unit]]: тип-синглтон
2.2.2 [[cs134b/int]]: знаковые целые числа
2.2.3 [[cs134b/float]]: числа с плавающей запятой
2.2.4 [[cs134b/char]]: одиночный символ
2.2.5 [[cs134b/string]]: строки символов
2.2.6 [[cs134b/bool]]: логические значения
