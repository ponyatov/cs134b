# 5.1.2 Другие виды полиморфизма

Помимо параметрического полиморфизма, который является основным и наиболее часто используемым в OCaml, язык поддерживает и другие формы полиморфизма, каждая из которых решает определённые задачи и расширяет выразительные возможности системы типов.

## ad-hoc полиморфизм (перегрузка операторов)

В отличие от многих языков, OCaml **не поддерживает** перегрузку операторов в традиционном смысле (когда один символ оператора может работать с разными типами). Однако существует ограниченная форма ад‑хок полиморфизма через **модули с сигнатурами** (см. главу 12) и **функторы**, которые позволяют определять обобщённые операции для типов с определёнными свойствами. Например, модуль `Set` требует, чтобы тип элементов имел функцию сравнения `compare`, что позволяет создавать множества для любого типа с заданным порядком.

## Субтипирование (подтипный полиморфизм)

OCaml предоставляет **ограниченную поддержку субтипирования** в рамках своей объектно‑ориентированной подсистемы (см. главы 14–17). Объекты в OCaml могут быть подтипами других объектов, что позволяет использовать их полиморфно через **субтипинг**. Однако, в отличие от языков вроде Java или C#, субтипирование в OCaml не распространяется на все типы данных, а только на объекты и массивы объектов.

```ocaml
class point x y = object
  method get_x = x
  method get_y = y
end

class colored_point x y c = object
  inherit point x y
  method color = c
end

let print_x p = print_int p#get_x  (* p : < get_x : int; .. > *)

let p = new point 3 4
let cp = new colored_point 1 2 "red"
let () = print_x p
let () = print_x cp  (* colored_point является подтипом point *)
```

## Полиморфные варианты (polymorphic variants)

Это специальная форма вариантных типов (tagged unions), которые не требуют явного объявления и обладают **структурной полиморфностью**. Полиморфные варианты обозначаются обратным апострофом (например, `` `Red ``, `` `Some of int ``) и могут использоваться в разных контекстах без привязки к одному конкретному типу.

```ocaml
let to_string = function
  | `Red -> "red"
  | `Green -> "green"
  | `Blue -> "blue"

let rgb = [`Red; `Green; `Blue]  (* тип: [< `Red | `Green | `Blue ] list *)

(* Полиморфные варианты могут быть расширены *)
let extended_to_string = function
  | `Red -> "red"
  | `Green -> "green"
  | `Blue -> "blue"
  | `Custom s -> s
```
