# Статический вывод типов

- все типы выражений определяются во время компиляции
- позволяет обнаружить широкий класс ошибок
- не требуется явно аннотировать типы в большинстве выражений
	- Компилятор способен автоматически **вывести** (infer) тип любого выражения на основе того, как оно используется
	- алгоритм Хиндли–Милнера
