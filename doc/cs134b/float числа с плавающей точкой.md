# 2.2.3 float: числа с плавающей точкой

Числа с плавающей точкой представляют вещественные числа в формате двойной точности (обычно 64 бита). Для операций с `float` используются специальные операторы с точкой: `+.`, `-.`, `*.`, `/.` и другие. Это отличает их от целочисленных операторов и предотвращает неявные преобразования, повышая ясность и безопасность кода.
