# char
## the character
### одиночный символ

В языке Objective Caml символы представляют собой отдельный базовый тип данных `char`

- записываются в **одинарных кавычках**
- **8-битные значения**,
	- соответствующими расширенному набору символов ASCII
	- кодировка ISO 8859-1, также известная как Latin-1

![[cs134b/escape-последовательности]]

- сравнение `< >`
- модуль `Char`

```ocaml
(* Проверка категории символа *)
Char.is_alpha 'a'     (* true: буква *)
Char.is_digit '7'     (* true: цифра *)
Char.is_upper 'Z'     (* true: заглавная буква *)
Char.is_lower 'x'     (* true: строчная буква *)
Char.is_space ' '     (* true: пробельный символ *)
Char.is_print '\n'    (* false: непечатаемый символ *)

(* Преобразование регистра *)
Char.lowercase_ascii 'A'   (* 'a' *)
Char.uppercase_ascii 'm'   (* 'M' *)

(* Преобразование в код и обратно *)
Char.code 'A'         (* 65: код символа 'A' *)
Char.chr 65           (* 'A': символ с кодом 65 *)
Char.chr 255          (* '\255': последний символ Latin-1 *)
```
