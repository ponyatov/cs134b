## Algebraic Data Type
### Алгебраические типы данных

OCaml позволяет программисту определять собственные сложные типы с помощью **алгебраических типов данных**. Они бывают двух основных видов:

- **Типы-произведения (Product types)**: кортежи (`tuple`) и записи (`record`). Значение такого типа содержит сразу несколько компонент (полей).
    
- **Типы-суммы (Sum types)**, или размеченные объединения (`variant`). Значение такого типа принадлежит одному из нескольких возможных вариантов (`constructor`), каждый из которых может нести свои данные.
