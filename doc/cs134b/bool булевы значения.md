# 2.2.6 bool: булевы значения

Логический тип `bool` содержит два значения: `true` (истина) и `false` (ложь). Он используется в условных выражениях (`if ... then ... else ...`), логических операциях `(&&`, `||`, `not`) и сравнениях (`=`, `<`, `>`, `<>` и другие). Все операции с булевыми значениями строго типизированы и не допускают автоматического приведения других типов к `bool`.
