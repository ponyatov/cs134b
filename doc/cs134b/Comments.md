# Comments
## Комментарии

- поддерживается только `(* блочный комментарий *)`
- может занимать несколько строк
- могут быть вложенными

```ocaml
(* Это однострочный комментарий *)
let x = 5 (* комментарий в конце строки *)
(* многостроный комментарий (* вложенный комментарий *)
продолжается на следующей строке *)
```
