# 2. Простые выражения

Простые выражения в OCaml представляют собой базовые строительные блоки программ. Они могут быть литералами (числа, строки, символы), именами переменных, применением операторов или вызовом функций. Каждое выражение имеет тип, который автоматически выводится системой типизации языка, что позволяет обнаруживать ошибки на ранних этапах разработки.

Примеры простых выражений:
- `42` — целочисленный литерал.
- `"hello"` — строковый литерал.
- `3.14` — литерал с плавающей точкой.
- `'A'` — символьный литерал.
- `x` — переменная.
- `1 + 2` — арифметическое выражение.
- `f x` — применение функции `f` к аргументу `x`.
