# `int`
## the integers
### знаковые целые числа

- поддерживаются стандартные арифметические операции
- типичный диапазон $\pm 2^{62}$ (или $\pm 2^{30}$ на 32-битной архитектуре)
	- 63/31 бит: представление целого числа включая знак
	- младший бит: тратится на внутреннее представление, VM языка OCaml отличает по нему числа от указателей памяти
		- 1: unboxed/immediate value хранится непосредственно в ячейке памяти или регистре (int)
		- 0: boxed value хранятся в куче, а в ячейке или регистре содержится указатель на этот объект (подавляющее большинство других типов)
