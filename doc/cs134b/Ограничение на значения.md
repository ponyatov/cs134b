# 5.1.1 Ограничение на значения
## Value Restriction

В системе типов OCaml существует важное правило, называемое **ограничением на значения (value restriction)**, которое обеспечивает корректность вывода типов при наличии изменяемых состояний и побочных эффектов. Это правило предотвращает небезопасный полиморфизм, который мог бы возникнуть при использовании изменяемых ссылок (`ref`) или других императивных конструкций.

## Суть ограничения

Если выражение не является **синтаксическим значением (syntactic value)** — то есть может выполнять вычисления или иметь побочные эффекты — то его тип не может быть обобщён (полиморфным) автоматически. Вместо этого компилятор присваивает такому выражению **монотип (monotype)** или требует явной аннотации типа.

**Синтаксические значения** — это выражения, которые вычисляются немедленно и не производят побочных эффектов. К ним относятся:

- Литералы: `42`, `"hello"`, `[]`
- Переменные: `x`
- Конструкторы данных: `Some x`, `(a, b)`
- Абстракции (функции): `fun x -> x * 2`

Рассмотрим потенциально опасный случай с изменяемой ссылкой:
```ocaml
let r = ref []  (* без ограничения тип был бы 'a list ref, что небезопасно *)
```

Если бы OCaml разрешил полиморфный тип `'a list ref` для `r`, то можно было бы записать в неё список одного типа, а затем прочитать как список другого типа, нарушив безопасность типов.

## Как работает ограничение

В OCaml выражение `ref []` не является синтаксическим значением (поскольку `ref` — это функция, создающая изменяемую ячейку). Поэтому его тип **не** обобщается до `'a list ref`, а становится **монотипом** с **свежей переменной типа (fresh type variable)**, которая может быть **инстанциирована** только один раз:

```ocaml
let r = ref []  (* тип: '_a list ref, где '_a — "свежий" тип, который ещё не определён *)
r := [1; 2; 3]  (* теперь '_a становится int, и тип r фиксируется как int list ref *)
```

> **После первого использования** `r` с конкретным типом (здесь `int`), переменная `'_a` *инстанциируется* в `int`, и дальнейшее использование `r` с другим типом приведёт к ошибке типизации.

## Обход ограничения

Если вам действительно нужна полиморфная изменяемая ссылка (например, для реализации полиморфного кеша), можно использовать синтаксическое значение — например, завернуть создание ссылки в функцию (которая является значением):
```ocaml
let make_ref () = ref []  (* тип: unit -> 'a list ref — полиморфная функция *)
let r1 : int list ref = make_ref ()
let r2 : string list ref = make_ref ()  (* разные инстанции полиморфного типа *)
```
