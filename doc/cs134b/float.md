# `float`
## the floating-point numbers
### числа с плавающей запятой

- соответствуют стандарту [[IEEE/754]]
	- двойной точности (64 бита) на большинстве платформ
	- `double` в языке Си
	- диапазон $\sim\pm1\times10^{308}$
- арифметические операции с плавающей запятой используют отдельный набор символов операторов c точкой в конце
	- подчеркивает строгое разделение типов int/float
- часто требуется явное преобразование между типами
	- `float (-123)`
	- `int_of_float (-2.9)`
- встроенные функции для логарифмов, тригонометрии и округления
