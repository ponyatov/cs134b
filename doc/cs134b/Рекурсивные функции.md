# 3.1.2 Рекурсивные функции

В OCaml ключевое слово `rec` используется при определении **рекурсивной функции** — то есть функции, которая вызывает саму себя в своём теле. Без `rec` функция не сможет ссылаться на своё собственное имя внутри своего определения.

```ocaml
let rec <имя_функции> <параметры> = <тело_функции>
```

Пример: сумма списка
```ocaml
let rec sum lst =
  match lst with
  | [] -> 0
  | head :: tail -> head + sum tail
```

- **Тип вывода** работает и с рекурсивными функциями — компилятор корректно определяет типы даже при наличии `rec`.
    
- **Область видимости**: рекурсивная функция видна в своём собственном теле, что и позволяет рекурсивные вызовы.

## Взаимная рекурсия

Для взаимно рекурсивных функций (когда две или более функций вызывают друг друга) используется and:

```ocaml
let rec is_even n =
  if n = 0 then true
  else is_odd (n - 1)

and is_odd n =
  if n = 0 then false
  else is_even (n - 1)
```

## Рекурсивные вложенные функции

Для определения рекурсивной вложенной функции используется `let rec ... in`. Такая функция может вызывать саму себя и имеет доступ к переменным внешней функции.

```ocaml
let fibonacci n =
	let rec fibonacci_ a b count =
		if count <= 0 then a
		else fibonacci_ b (a + b) (count - 1)
	in
	  if n < 0 then invalid_arg "fibonacci: negative input"
	  else fib_helper 0 1 n;;
```

1. **Внешняя функция `fibonacci n`**:
    
    - Проверяет корректность входных данных (n не должно быть отрицательным).
    - Вызывает вложенную функцию `fibonacci_` с начальными значениями.
        
2. **Вложенная функция `fibonacci_ a b count`**:
    
    - `a` и `b` — два последовательных числа Фибоначчи на текущем шаге.
    - `count` — сколько шагов осталось выполнить.
    - На каждом шаге функция сдвигает пару `(a, b)` к следующей паре `(b, a+b)`.
    - Когда `count` достигает 0, возвращается текущее значение `a`.
        
3. **Хвостовая рекурсия**:
    
    - Поскольку рекурсивный вызов является последней операцией в функции, компилятор OCaml может оптимизировать его в цикл, избегая переполнения стека.

Вложенные функции часто используются для:

- **Инкапсуляции вспомогательной логики**, которую не нужно экспортировать.
- **Создания замыканий** для callback-ов или генераторов.
- **Оптимизации** через накопление результатов (аккумуляторы) в хвостовой рекурсии.
