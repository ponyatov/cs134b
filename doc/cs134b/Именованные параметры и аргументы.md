# 3.3 Именованные параметры и аргументы

В OCaml существует возможность использовать **именованные параметры** (labeled parameters) и **необязательные параметры** (optional parameters) в функциях. Эти механизмы повышают читаемость кода, особенно при вызове функций с большим количеством аргументов, и позволяют задавать значения по умолчанию для некоторых параметров.

Именованный параметр указывается с помощью тильды `~` перед именем параметра в объявлении функции. При вызове функции аргументы можно передавать в любом порядке, указывая имя параметра.

```ocaml
let labeled_add ~x ~y = x + y
```

Тип этой функции будет `x:int -> y:int -> int`. Вызвать её можно несколькими способами:

```ocaml
labeled_add ~x:3 ~y:4     (* 7 *)
labeled_add ~y:4 ~x:3     (* тоже 7, порядок не важен *)
```

## Упрощённая запись

Если имя параметра и переменной, передаваемой в качестве аргумента, совпадают, можно использовать сокращённую запись:
```ocaml
let x = 3
let y = 4
labeled_add ~x ~y          (* эквивалентно labeled_add ~x:x ~y:y *)
```

## Типизация с именованными параметрами

Типы выводятся автоматически, но можно явно указать аннотации::
```ocaml
let distance ~(x1:float) ~(y1:float) ~(x2:float) ~(y2:float) =
  sqrt ((x2 -. x1) ** 2. +. (y2 -. y1) ** 2.)
```

## Необязательные параметры

Необязательные параметры обозначаются с помощью знака вопроса ? перед именем параметра. При вызове функции их можно опускать.

```ocaml
let greet ?(prefix = "Hello") name = 
  prefix ^ ", " ^ name
```
```ocaml
greet "Alice"                 (* "Hello, Alice" *)
greet ~prefix:"Hi" "Bob"      (* "Hi, Bob" *)
```

## Без значения по умолчанию

Если значение по умолчанию не указано, параметр имеет тип `'a option`:
```ocaml
let connect ?timeout host =
  match timeout with
  | None   -> "Connecting to " ^ host ^ " with default timeout"
  | Some t -> "Connecting to " ^ host ^ " with timeout " ^ string_of_int t
```

## Комбинация именованных и необязательных параметров

```ocaml
let create_user ~name ?(age = 18) ?email () =
  let email_str = match email with
    | None -> "no email"
    | Some e -> e
  in
  "User: " ^ name ^ ", age: " ^ string_of_int age ^ ", email: " ^ email_str
```

Обратите внимание на **unit-параметр `()`** в конце. Это распространённый паттерн для функций с необязательными параметрами, который помогает компилятору правильно определить момент полного применения функции.

```ocaml
create_user ~name:"Alice" ()                     (* возраст по умолчанию, email отсутствует *)
create_user ~name:"Bob" ~age:25 ()               (* email отсутствует *)
create_user ~name:"Carol" ~email:"c@example.com" ()  (* возраст по умолчанию *)
```

## Применение в реальных задачах

1. **Конфигурация функций**: когда функция имеет много параметров настройки
```ocaml
let draw_circle ~x ~y ~radius ?(color = "black") ?(thickness = 1) () =
  (* ... *)
```
2. **API библиотек**: улучшение читаемости вызовов функций
```ocaml
Database.connect ~host:"localhost" ~port:5432 ~database:"test" ()
```
3. **Постепенное усложнение**: добавление новых параметров без ломания существующего кода

## Ограничения и особенности

- **Порядок вызова**: именованные аргументы можно передавать в любом порядке, но позиционные аргументы должны идти до любых именованных
    
- **Вывод типов**: при использовании необязательных параметров может потребоваться аннотация типов для избежания неоднозначности
    
- **Производительность**: именованные и необязательные параметры компилируются в эффективный код, без накладных расходов в рантайме

## Практические рекомендации

1. Используйте именованные параметры, когда функция принимает более двух аргументов
    
2. Для булевых флагов предпочтительнее использовать именованные параметры, чем позиционные
    
3. Всегда включайте единичный параметр `()` в конец функций с необязательными параметрами
    
4. Документируйте значения по умолчанию для необязательных параметров
