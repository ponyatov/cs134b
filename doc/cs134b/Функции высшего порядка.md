# 3.1.3 Функции высшего порядка

Функции высшего порядка (higher-order functions) — это функции, которые принимают другие функции в качестве аргументов или возвращают их в качестве результата. Эта возможность является одной из краеугольных концепций функционального программирования и предоставляет **мощные средства абстракции и композиции** в OCaml.

В OCaml функции являются **первоклассными значениями** (first-class citizens). Это означает, что с ними можно работать как с любыми другими данными: передавать в функции, сохранять в структурах данных, создавать динамически. Синтаксис объявления функции высшего порядка ничем не отличается от обычного — типы аргументов и возвращаемого значения указываются в сигнатуре.

## `apply_twice`

пример функции, которая принимает функцию `f` и значение `x`, и применяет `f` к `x` дважды:
```ocaml
let apply_twice f x = f (f x)
```
```ocaml
val apply_twice : ('a -> 'a) -> 'a -> 'a = <fun>
```

Тип этой функции будет выведен как `('a -> 'a) -> 'a -> 'a`, что означает: она принимает функцию из типа `'a` в `'a` и значение типа `'a`, возвращая результат того же типа `'a`.

```ocaml
let square x = x * x
let result = apply_twice square 2
```
```ocaml
val result : int = 16
(* = 16, так как square(square(2)) = square(4) = 16 *)
```

## Стандартные функции высшего порядка

OCaml предоставляет богатый набор функций высшего порядка в стандартной библиотеке, особенно в модулях `List`, `Array` и `Option`. Наиболее часто используемые:

### `List.map`

Применяет функцию ко всем элементам списка и возвращает новый список результатов.
```ocaml
let list = List.map (fun x -> x * 2) [1; 2; 3]  (* [2; 4; 6] *)
```

### `List.filter`

Возвращает список элементов, для которых заданная функция-предикат возвращает true.
```ocaml
let evens = List.filter (fun x -> x mod 2 = 0) [1; 2; 3; 4]  (* [2; 4] *)
```

### `List.fold_left` и `List.fold_right`

Агрегируют элементы списка в одно значение, последовательно применяя функцию аккумуляции.
```ocaml
let sum = List.fold_left (fun acc x -> acc + x) 0 [1; 2; 3]  (* 6 *)
```
