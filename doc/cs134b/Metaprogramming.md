# 18. Metaprogramming
## Метапрограммирование

> программы которые пишут программы

You can think of it as a program which works with another program as data at compile time. [[cs134b/ppx|ppx]] is the OCaml syntax extension allowing programmers to meta-program directly on the abstract syntax tree (AST) of OCaml code. This means simple tasks like writing (de)serialization can be automated through clever inference on types.
