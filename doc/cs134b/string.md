# string
## character strings
### строки символов

- иммутабельные последовательности символов типа [[cs134b/char|char]]
	- Любая операция, "изменяющая" строку, на самом деле создает новую
- в "двойных кавычках" (поддержка многострочности и [[cs134b/escape-последовательности|escape-последовательностей]])
- в `{| многострочные строки с отключенными escape и кавычками |}`
- конкатенация через оператор `"" ^ ""`
- доступ по индексу через `.[n]`
- сравнение через `< >`

## модуль `String`

- длина строки `String.length ""`
- Поиск и извлечение подстрок
- Преобразование строк
