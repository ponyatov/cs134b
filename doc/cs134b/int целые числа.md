# 2.2.2 int: целые числа

Целые числа в [[OCaml/OCaml|OCaml]] представляют собой знаковые целочисленные значения фиксированного размера, обычно 31 или 63 бита в зависимости от платформы.

Они поддерживают стандартные арифметические операции: сложение (`+`), вычитание (`-`), умножение (`*`), целочисленное деление (`/`), взятие остатка (`mod`), а также битовые операции. Все операции над целыми числами строго типизированы — нельзя смешивать целые числа с числами с плавающей точкой без явного преобразования.
