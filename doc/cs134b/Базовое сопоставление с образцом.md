# 4. Базовое сопоставление с образцом

Сопоставление с образцом (pattern matching) — одна из наиболее мощных и обязательно используемых возможностей OCaml. Это механизм декомпозиции структур данных и проверки их формы, который позволяет писать выразительный и безопасный код, заменяя собой многоуровневые условные конструкции, типичные для императивных языков.

## Базовый синтаксис

Конструкция `match ... with` является основным способом сопоставления с образцом:
```ocaml
match выражение with
| образец1 -> результат1
| образец2 -> результат2
...
| образецN -> результатN
```

Выражение вычисляется, и его значение последовательно сравнивается с каждым образцом сверху вниз. При первом совпадении выполняется соответствующая ветка, и её результат становится результатом всего выражения `match`.

## Простые образцы

### Литералы

```ocaml
let describe_number n =
  match n with
  | 0 -> "zero"
  | 1 -> "one"
  | 2 -> "two"
  | _ -> "many"  (* образец "_" соответствует любому значению *)
```

### Переменные

```ocaml
let is_zero n =
  match n with
  | 0 -> true
  | x -> false  (* "x" свяжет любое значение с именем x, но здесь это избыточно *)
```

### Образец-подстановка (as-pattern)

Позволяет одновременно сопоставить значение с образцом и связать его с именем:

```ocaml
let first_of_pair p =
  match p with
  | (x, _) as pair -> (x, pair)  (* -> (x , (x , ... )) *)
```

## Сопоставление с составными типами

### Кортежи

```ocaml
let add_pair p =
  match p with
  | (x, y) -> x + y
```

### Списки

```ocaml
let head_of_list lst =
  match lst with
  | [] -> None
  | hd :: _ -> Some hd
```

### Вариантные типы (алгебраические типы данных)

```ocaml
type shape =
  | Circle of float
  | Rectangle of float * float

let area s =
  match s with
  | Circle r -> 3.14159 *. r *. r
  | Rectangle (w, h) -> w *. h
```

## Охранные выражения (when guards)

Для добавления дополнительных условий к образцам используется ключевое слово `when`:
```ocaml
let categorize n =
  match n with
  | x when x < 0 -> "negative"
  | 0 -> "zero"
  | x when x > 0 && x < 10 -> "small positive"
  | _ -> "large positive"
```

## Исчерпывающая проверка

Компилятор OCaml проверяет, покрывают ли образцы все возможные случаи. Если какой-то случай не обработан, выдаётся предупреждение:
```ocaml
type color = Red | Green | Blue

let color_to_string c =
  match c with
  | Red -> "red"
  | Green -> "green"
  (* предупреждение: не обработан случай Blue *)
```

Это одна из самых мощных особенностей системы типов OCaml — многие ошибки обнаруживаются на этапе компиляции, а не выполнения.

## Сопоставление с образцом в let-связываниях

Сопоставление с образцом можно использовать непосредственно в `let`:

```ocaml
let (x, y) = (1, 2)          (* x = 1, y = 2 *)
let hd :: tl = [1; 2; 3]     (* hd = 1, tl = [2; 3] *)
```

если образец не совпадёт, будет вызвано исключение `Match_failure`.

## Эффективность

Сопоставление с образцом компилируется в эффективный код, обычно в виде таблиц переходов (jump table) или последовательности проверок. Компилятор OCaml оптимизирует сопоставление, особенно для целых чисел и вариантных типов.

## Практическое применение

1. **Обработка ошибок**: вместо исключений можно использовать тип `result` с сопоставлением
2. **Рекурсивные обходы структур**: особенно удобно для деревьев и AST
```ocaml
type expr =
  | Const of int
  | Add of expr * expr
  | Mul of expr * expr

let rec eval = function
  | Const n -> n
  | Add (e1, e2) -> eval e1 + eval e2
  | Mul (e1, e2) -> eval e1 * eval e2
```
3. **Разбор входных данных**: например, при обработке командной строки или сетевых протоколов

Сопоставление с образцом — не просто синтаксический сахар, а фундаментальный инструмент мышления в функциональном программировании. Оно поощряет полную обработку всех случаев, что приводит к более надёжному и поддерживаемому коду. В сочетании с алгебраическими типами данных сопоставление с образцом образует выразительную систему, которая широко применяется в компиляторах, верификационных инструментах и других областях, где корректность кода критически важна.
