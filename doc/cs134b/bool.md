# bool
## the Boolean values
### логические значения

Булев тип в OCaml (`bool`)

- является простейшим алгебраическим типом данных, состоящим ровно из двух конструкторов:
	- `true` (истина)
	- `false` (ложь)
- отдельный тип, не сопоставляемый с `int` как в Си

## операторы

- **ленивые** (short-circuit): правый операнд вычисляется только при необходимости
	- `&&`
	- `||`
- `not`
- сравнение
	- `=`
	- `<>`
