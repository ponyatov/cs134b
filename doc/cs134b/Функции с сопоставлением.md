# 4.1 Функции с сопоставлением

В OCaml сопоставление с образцом тесно интегрировано с определением функций. Фактически, каждая функция, принимающая аргументы, неявно выполняет сопоставление с образцом этих аргументов. Существует специальный синтаксис, позволяющий определять функции непосредственно через сопоставление с образцом, что делает код более лаконичным и выразительным.

Ключевое слово `function` позволяет определить функцию одного аргумента с немедленным сопоставлением с образцом:
```ocaml
let имя = function
| образец1 -> выражение1
| образец2 -> выражение2
...
| образецN -> выражениеN
```

Эта запись эквивалентна:
```ocaml
let имя x = match x with
| образец1 -> выражение1
| образец2 -> выражение2
...
| образецN -> выражениеN
```

## Синтаксис `fun` с несколькими аргументами

Для функций нескольких аргументов можно использовать комбинацию `fun` с сопоставлением:
```ocaml
let add_pair = fun (x, y) -> x + y
```
Или в более краткой форме:
```ocaml
let add_pair (x, y) = x + y
```
