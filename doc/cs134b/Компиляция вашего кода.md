# 2.5 Компиляция вашего кода

Компиляция в [[OCaml/OCaml|OCaml]] осуществляется с помощью набора инструментов, входящих в стандартную поставку языка. Основные компоненты включают компиляторы `ocamlc` (байткод-компилятор) и `ocamlopt` (нативный компилятор), а также интерактивную среду выполнения `ocaml` (toplevel = REPL). Каждый из этих инструментов предназначен для определённых задач и этапов разработки.

- `lib/main.ml`
	```ocaml
	let () =
	  print_endline "Hello World"
	```

- [[ocamlc]]: компилятор в байт-код
	- транслирует исходный код OCaml в байткод, который затем выполняется виртуальной машиной OCaml
		- быстрая компиляция
		- кроссплатформенная переносимость
		- поддержка динамической загрузки кода
	```sh
	$ ocamlc -o ./tmp/main ./lib/main.ml
	$ file ./tmp/main
	/tmp/main: a /home/dponyatov/.opam/cs3110/bin/ocamlrun script executable (binary data)
	$ ./tmp/main
	Hello World
	```
- [[ocamlopt]]: компилятор в нативный машинный код
	- оптимизированный машинный код для целевой платформы
	- сравнимые по скорости с программами на C
	- компиляция занимает больше времени
	```sh
	$ ocamlopt -o ./tmp/main ./lib/main.ml
	$ file ./tmp/main
	./tmp/main: ELF 64-bit LSB pie executable, x86-64, version 1 (SYSV), 
	dynamically linked, interpreter /lib64/ld-linux-x86-64.so.2
	$ ./tmp/main
	Hello World
	```

## Управление зависимостями и проектами

Для сборки многомодульных проектов используется система управления сборкой `ocamlbuild` или более современные инструменты, такие как [[OCaml/dune|dune]]. Они автоматизируют компиляцию, линковку и управление зависимостями, включая внешние библиотеки из OPAM — менеджера пакетов OCaml.

![[cs134b/dune-project|dune-project]]
![[cs134b/dune|dune]]
```sh
$ dune build
$ dune exec cs134b
```

## Отладка и профилирование

OCaml предоставляет инструменты для отладки байткода (`ocamldebug`) и профилирования нативного кода (`gprof`, `perf`). Для анализа использования памяти и времени выполнения можно использовать библиотеки, такие как `ocaml-memprof` или встроенные средства профилирования `ocamlopt -p`.
