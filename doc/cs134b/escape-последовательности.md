# escape-последовательности

```ocaml
'\n'    (* новая строка (line feed, LF) *)
'\t'    (* горизонтальная табуляция *)
'\r'    (* возврат каретки (carriage return, CR) *)
'\b'    (* забой (backspace) *)
'\\'    (* обратная косая черта *)
'\''    (* одинарная кавычка *)
'\000'  (* нулевой символ (ASCII NUL) *)
'\255'  (* символ с кодом 255 *)
```
