# Функциональные и императивные языки

[[OCaml/OCaml|OCaml]] является мультипарадигменным языком программирования, что означает возможность написания кода в функциональном, императивном или объектно-ориентированном стиле в зависимости от потребностей задачи. Это позволяет разработчикам выбирать наиболее подходящий подход для каждого конкретного случая, сочетая преимущества разных парадигм в одном проекте.

1. **Функциональный стиль**  
    - Программы строятся из выражений, а не последовательности инструкций.
    - Функции являются “первоклассными” объектами
	    - их можно передавать, возвращать,
		- создавать и модифицировать в рантайме
    - Неизменяемые данные и отсутствие побочных эффектов в чисто функциональных частях.
	    - повышает надёжность и предсказуемость кода
	    - иммутабельные данные это ключевое свойство для эффективной многопоточности
2. **Императивный стиль**  
	- Использование ссылочных ячеек (`ref`), изменяемых записей, массивов.  
	- Побочные эффекты, циклы `for`/`while`, последовательности команд.
	- для ситуаций, где требуется явное управление памятью или состоянием системы
3. **ООП**
	- Моделирование состояний с изменяемым поведением
	- прототипирование сложных систем
	- построение пользовательских интерфейсов

OCaml позволяет выбирать стиль в зависимости от задачи:
- Функциональный — для преобразования данных, компиляторов
- Императивный — для ввода-вывода, взаимодействия с железом
